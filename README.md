# OralPrep: תרגול הבגרות בעל פה באנגלית (COBE)

מערכת Web למורים ולתלמידים לתרגול הבחינה בעל פה באנגלית לאורך כל שנת הלימודים.

- **מורים:** יוצרים או מעלים מבחנים, מקצים אותם לכיתות, מאזינים להקלטות ונותנים ציון ומשוב לפי מחוון.
- **תלמידים:** מקליטים תשובות מכל מכשיר, כולל טלפון.
- **בלי בינה מלאכותית:** כל הבדיקה והציון נעשים על ידי המורה בלבד.

> זוהי **סימולציה עצמאית לתרגול**. היא אינה מערכת הבחינה הרשמית של משרד החינוך, אינה iTest, ואינה מעניקה ציון בגרות.

## מה יש במערכת

| תפקיד | יכולות |
|---|---|
| **מורה** | **כיתות ותלמידים:** יצירת כיתות. הוספת תלמידים לפי שם (המערכת יוצרת שם משתמש וסיסמה זמנית להדפסה) או בקוד הצטרפות. איפוס סיסמה, הסרה או מחיקה מלאה של תלמיד.<br>**מבחנים:** עורך מבחנים עם שמירה אוטומטית ובו חלקים, שאלות, סטים של שאלות, בחירת נושא, שמע (העלאה או הקלטה במיקרופון), וידאו, תמונה, זמן הכנה וזמן הקלטה, הקלטה חוזרת והגבלת השמעות. יש תבנית COBE, ייבוא מבחן מוכן (PDF, Word, שמע, וידאו) עם שיוך ידני של קבצים לשאלות, ותצוגה מקדימה כפי שהתלמיד רואה.<br>**הקצאה:** מצב תרגול או סימולציה. הקצאה לכיתה או לתלמידים מסוימים, עם מועד פתיחה, מועד הגשה ומספר ניסיונות.<br>**בדיקה:** מסך בדיקה עם נגן הקלטות (במהירות 1×, 1.25× או 1.5×), מחוון בארבע רמות, משוב לכל שאלה ומשוב כללי, טיוטה או פרסום, והחזרה לתלמיד לתרגול נוסף.<br>**מעקב:** לוח בקרה, מגמת ציונים, תלמידים שלא הגישו, והתקדמות של כל תלמיד לאורך השנה.<br>**מאגר משותף:** שיתוף במאגר עם אישור זכויות, חיפוש, העתקה לספרייה האישית, והסרה. |
| **תלמיד** | **משימות:** רשימת משימות, ובדיקת מיקרופון עם הקלטת ניסיון והשמעה.<br>**ביצוע:** ממשק ביצוע מותאם לטלפון, עם טיימר, זמן הכנה, מד עוצמת קול, הקלטה חוזרת וחיווי שמירה. אם הרשת נופלת, ההקלטות נשמרות במכשיר ומועלות אוטומטית כשהיא חוזרת.<br>**הגשה ותוצאות:** הגשה אחת בלבד (לא ניתן להגיש פעמיים), ציונים ומשוב, והיסטוריה עם מגמת ציונים. |
| **מנהל מערכת** | בתי ספר וקודי הצטרפות למורים, מדיניות שמירת הקלטות, יצירה, השבתה ומחיקה של משתמשים, ניהול המאגר המשותף ויומן פעולות רגישות. |

## ארכיטקטורה

- **Next.js 15 (App Router) ו־TypeScript.** אפליקציה אחת שכוללת את ה־UI ואת ה־backend (Server Actions ו־Route Handlers).
- **PostgreSQL ו־Prisma**, עם migrations ב־`prisma/migrations`.
- **אחסון קבצים פרטי** עם דרייבר מקומי (לפיתוח) או S3-compatible (R2, S3, MinIO). העלאה ישירה מהדפדפן ב־URL חתום, ואחריה אימות בשרת של הגודל ושל תוכן הקובץ.
- **אימות** מבוסס sessions בצד השרת. ההרשאות מרוכזות ב־`src/lib/authz.ts`.
- **Tailwind CSS 4** עם RTL מלא. תוכן באנגלית מוצג LTR.
- **ללא שירותים בתשלום וללא AI.**

```
src/
  app/(auth)/        התחברות, הרשמת מורה, הצטרפות תלמיד, שינוי סיסמה
  app/t/             ממשק מורה (כיתות, מבחנים, משימות, בדיקה, מאגר, מחוונים)
  app/s/             ממשק תלמיד (משימות, ביצוע מבחן, תוצאות, היסטוריה)
  app/admin/         ניהול מערכת
  app/preview/[id]   תצוגה מקדימה (נגן התלמיד במצב מקומי)
  app/api/           העלאות, גישה למדיה, התקדמות והגשת ניסיון, דרייבר אחסון מקומי
  components/runner/ נגן המבחן, בדיקת מיקרופון, תור העלאות עמיד
  lib/               auth, authz, attempts, exams, scoring, files, storage, cobe
prisma/              schema, migrations, seed
scripts/             create-admin, demo-data, retention
tests/               unit + integration (Vitest, מול Postgres אמיתי)
e2e/                 Playwright: זרימה מלאה עם מיקרופון מדומה
docs/                מחקר, פריסה, אבטחה ופרטיות, מגבלות
```

## הפעלה מקומית

דרישות: Node 20 ומעלה, PostgreSQL 14 ומעלה, ו־ffmpeg (רק לנתוני הדגמה ולבדיקות E2E).

```bash
npm install
cp .env.example .env              # ולעדכן DATABASE_URL ו־APP_SECRET
npx prisma migrate deploy
npm run db:seed                   # מחוון ברירת המחדל
npm run admin:create -- admin@example.org "Admin"
npm run dev                       # http://localhost:3000
```

נתוני הדגמה, מסומנים בבירור כהדגמה ונפרדים מנתונים אמיתיים:

```bash
npm run db:demo                   # מדפיס פרטי כניסה של מורה ותלמידים לדוגמה
npm run db:demo -- --remove       # מוחק אותם
```

## בדיקות

```bash
npm run typecheck && npm run lint
npm test                          # Vitest: 41 בדיקות unit + integration (DB נפרד: cobe_test)
npm run build && npm run test:e2e # Playwright: 14 בדיקות E2E (DB נפרד: cobe_e2e)
```

בדיקות ה־E2E רצות בדפדפן אמיתי עם מיקרופון מדומה, שמייצר צליל אמיתי. כך נבדקים הקלטה, העלאה, שמירה, האזנה והגשה בפועל. התרחישים:

- הרשמת מורה, יצירת כיתה ותלמידים.
- בניית מבחן COBE עם וידאו, פרסום והקצאה.
- ייבוא PDF ושמע, כולל דחיית קובץ מזויף.
- כניסת תלמיד, החלפת סיסמה, בדיקת מיקרופון, הקלטת 4 תשובות והגשה.
- ניסיון הגשה כפולה.
- האזנת המורה, ציון לפי מחוון ופרסום, והצגת הציון לתלמיד.
- שיתוף והעתקה מהמאגר.
- בידוד הרשאות בין מורים ובין תלמידים, CSRF ומיקרופון חסום.
- ניתוק רשת באמצע העלאה.
- סימולציה: זמן הכנה, הקלטה אוטומטית ועצירה אוטומטית, ופקיעת זמן עם הגשה אוטומטית.
- ממשק מנהל.

אותו סט נבדק גם מול אחסון S3 (`E2E_STORAGE=s3`).
