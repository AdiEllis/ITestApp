# הפעלה בחינם, צעד אחר צעד

המערכת רצה על שלושה שירותים עם מסלול חינמי. **אף אחד מהם לא מבקש כרטיס אשראי** בהרשמה (נכון לבדיקה באוקטובר 2026). כדאי לוודא שלא מסומן מסלול בתשלום בזמן ההרשמה.

| מה | שירות | מסלול חינמי | מספיק ל־ |
|---|---|---|---|
| השרת (האתר עצמו) | **Vercel** – מסלול Hobby | חינם | כיתות של מורה אחת, בלי הגבלה מעשית |
| בסיס נתונים | **Neon** – מסלול Free | 0.5GB | מאות תלמידים לאורך שנים (רק טקסט וציונים) |
| הקלטות וקבצים | **Backblaze B2** | 10GB | כ־10,000 הקלטות של שתי דקות. סרטונים תופסים יותר מקום |

זמן משוער: 15–20 דקות, פעם אחת. בפועל נדרשות **שתי הרשמות** בלבד, Backblaze ו־Vercel. בסיס הנתונים נוצר מתוך Vercel.

---

## שלב 1: Backblaze B2 (אחסון ההקלטות)

1. נכנסים ל־**backblaze.com**, ובוחרים **B2 Cloud Storage** ← **Sign Up** (חינם, 10GB).
2. בתפריט: **Buckets** ← **Create a Bucket**:
   - **Bucket Unique Name:** שם ייחודי באנגלית, למשל `oralprep-adi-2026`.
   - **Files in Bucket are:** לבחור **Private**. זה חשוב, כדי שההקלטות של התלמידים לא יהיו ציבוריות.
   - **Create a Bucket.**
3. ב־bucket שנוצר מופיעה שורת **Endpoint**, למשל `s3.us-east-005.backblazeb2.com`. **שומרים אותה.**
4. בתפריט: **Application Keys** ← **Add a New Application Key**:
   - **Name:** `oralprep`.
   - **Allow access to Bucket(s):** ה־bucket שיצרת.
   - **Type of Access:** **Read and Write**.
   - **Create New Key.**
5. מופיעים שני ערכים: **keyID** ו־**applicationKey**. **שומרים את שניהם מיד**, כי ה־applicationKey מוצג פעם אחת בלבד.

## שלב 2: Vercel (השרת ובסיס הנתונים)

1. נכנסים ל־**vercel.com** ← **Sign Up** ← **Hobby** ← **Continue with GitHub**, עם חשבון ה־GitHub שבו נמצא `AdiEllis/ITestApp`.
2. **Add New…** ← **Project** ← לצד `ITestApp` לוחצים **Import**.
3. פותחים את **Environment Variables** ומוסיפים את המשתנים הבאים. בכל שורה: שם בצד שמאל, ערך בצד ימין.

   | Name | Value |
   |---|---|
   | `STORAGE_DRIVER` | `s3` |
   | `S3_ENDPOINT` | `https://` ואחריו ה־Endpoint משלב 1, למשל `https://s3.us-east-005.backblazeb2.com` |
   | `S3_REGION` | החלק האמצעי של ה־Endpoint, למשל `us-east-005` |
   | `S3_BUCKET` | שם ה־bucket |
   | `S3_ACCESS_KEY_ID` | ה־keyID |
   | `S3_SECRET_ACCESS_KEY` | ה־applicationKey |
   | `CRON_SECRET` | מחרוזת ארוכה כלשהי באנגלית ובמספרים, לפחות 20 תווים. משמשת את משימת הניקוי היומית |

4. לוחצים **Deploy**. הפריסה הראשונה **תיכשל**, כי עדיין אין בסיס נתונים. זה צפוי.
5. בפרויקט ב־Vercel: לשונית **Storage** ← **Create Database** ← **Neon** ← מסלול **Free**, אזור **Frankfurt** ← **Connect** לפרויקט.

   Vercel יוצר את בסיס הנתונים ומוסיף את `DATABASE_URL` ואת `DATABASE_URL_UNPOOLED` בעצמו, בלי חשבון נוסף.
6. **Deployments** ← בפריסה האחרונה **⋯** ← **Redeploy**, ומחכים 2–4 דקות. בסוף מופיעה כתובת האתר, למשל `https://itestapp.vercel.app`.

   בזמן הבנייה המערכת מכינה את בסיס הנתונים ומגדירה את האחסון בעצמה. אם משהו חסר או שגוי, הבנייה נכשלת עם הודעה ברורה.
7. **(מומלץ)** ב־Vercel: **Settings** ← **Environment Variables** ← מוסיפים `APP_URL` עם כתובת האתר, ואז **Deployments** ← **Redeploy**.

## שלב 3: בדיקה ראשונה (5 דקות)

1. נכנסים לכתובת האתר ← **פתיחת חשבון מורה**.
2. יוצרים כיתה ומוסיפים תלמיד/ת ניסיון.
3. יוצרים מבחן ← **מבנה COBE**. מעלים סרטון קצר ל־Part C ← **פרסום** ← **הקצאה לכיתה**.
4. מהטלפון: נכנסים עם פרטי התלמיד ← בדיקת מיקרופון ← מקליטים תשובה ← מגישים.
5. מהמחשב: **בדיקת הגשות** ← מאזינים ← נותנים ציון ← **פרסום**.

אם ההקלטה לא נשמרת בשלב 4, בודקים ב־Vercel שה־`S3_*` הוזנו נכון. ההגדרה האוטומטית של ה־bucket רצה בכל פריסה, ולכן אחרי תיקון עושים **Redeploy**.

## חשוב לדעת על המסלולים החינמיים

- **Vercel Hobby** מיועד לשימוש **אישי ולא מסחרי**. מורה שמשתמשת במערכת עם הכיתות שלה, בלי לגבות כסף, מתאימה לזה. אם בעתיד בית ספר שלם ישתמש בה כשירות, צריך לבדוק את התנאים.
- **Neon Free** "נרדם" אחרי כמה דקות בלי שימוש. הכניסה הראשונה אחרי הפסקה איטית בשנייה או שתיים, ואחר כך הכול רגיל. הנתונים לא נמחקים.
- **Backblaze B2:** אם עוברים 10GB, Backblaze יבקשו להוסיף אמצעי תשלום, אבל לא יחייבו אוטומטית. כדי לא להגיע לשם:
  - קובעים שמירת הקלטות (ברירת המחדל: 400 יום).
  - מעדיפים סרטונים קצרים ודחוסים.
  - מוחקים משימות ישנות.

  ב־Backblaze אפשר לראות את נפח האחסון בכל רגע.
- **משימת הניקוי** (מחיקת הקלטות לפי מדיניות השמירה) רצה אוטומטית פעם ביום דרך Vercel Cron, וזה כלול בחינם.

## מנהל מערכת (לא חובה)

כמורה יחידה אין צורך בחשבון מנהל: חשבון המורה מספיק לכל העבודה. מנהל נדרש רק כדי:

- לנהל כמה בתי ספר.
- לשנות את מדיניות השמירה לבית ספר.
- להסיר תכנים של אחרים מהמאגר.

ליצירת מנהל צריך להריץ פקודה אחת מול בסיס הנתונים (`npm run admin:create`). אפשר לבקש ממני לעשות זאת כשיהיה צורך.
