# הקראת השאלות

## איך זה עובד
- לכל שאלה יש **קובץ הקראה אחד**. המורה יוצרת אותו בלחיצה ("יצירת הקראה אוטומטית") או מקליטה את השאלה בקולה.
- המורה מאזינה עד הסוף ומסמנת "האזנתי להקראה, והיא קוראת את השאלה נכון".
- **אי אפשר לפרסם מבחן** כשיש שאלה בלי הקראה מאושרת.
- כל התלמידים שומעים **בדיוק אותו קובץ** שהמורה אישרה, בכל מחשב או טלפון. ההקראה מתחילה לבד כשהתלמיד/ה מגיע/ה לשאלה, ואפשר לשמוע שוב.
- אם משנים את נוסח השאלה אחרי שההקראה נוצרה, המערכת מסמנת "השאלה השתנתה" ומבקשת הקראה חדשה.

## כשהקול טועה במילה
עברית נכתבת בלי ניקוד, ולכן קול ממוחשב יכול לקרוא מילה לא נכון. אפשר:
1. לכתוב את השאלה עם ניקוד.
2. או למלא "נוסח להקראה": התלמיד/ה רואה את השאלה הרגילה ושומע/ת את הנוסח הזה. שם כותבים מילים בעייתיות עם ניקוד, בכתיב מלא, ומספרים או תאריכים במילים.
3. ללחוץ "יצירת הקראה אוטומטית מחדש" ולהאזין שוב.
4. אם עדיין לא טוב, להקליט את השאלה בקול שלך.

## הפעלת הקול האוטומטי (פעם אחת, כ־15 דקות)
בלי ההגדרה הזו האתר עובד, ופשוט אין כפתור "יצירת הקראה אוטומטית". המורה מקליטה את השאלות בקולה, ויכולה לשמוע את השאלה בקול המחשב ("השמעת השאלה בקול המחשב"; בדפדפן Edge הקול בעברית הכי טוב).

הקול המומלץ לעברית הוא של Microsoft (קול נשי "Hila" או קול גברי "Avri"). יש מסלול חינמי של 500,000 תווים בחודש, בערך 3,000 שאלות.

1. נכנסים ל־**portal.azure.com** ופותחים חשבון חינמי (מבקשים כרטיס אשראי לאימות, אבל במסלול החינמי F0 לא מחייבים).
2. למעלה בחיפוש כותבים **Speech** ובוחרים **Speech services** ← **Create**.
3. ממלאים:
   - **Region**: ‏West Europe.
   - **Name**: למשל `oralprep-voice`.
   - **Pricing tier**: ‏**Free F0**.
   - לוחצים **Review + create** ← **Create**, ומחכים דקה.
4. נכנסים למשאב שנוצר ← **Keys and Endpoint**. מעתיקים את **KEY 1** ואת **Location/Region** (למשל `westeurope`).
5. ב־**Vercel** ← הפרויקט ← **Settings** ← **Environment Variables**, מוסיפים:
   - `AZURE_SPEECH_KEY` = המפתח שהעתקתם.
   - `AZURE_SPEECH_REGION` = האזור (למשל `westeurope`).
   - לא חובה: `AZURE_TTS_VOICE` = ‏`he-IL-AvriNeural` לקול גברי.
   - בכל משתנה מסמנים גם **Production** וגם **Preview**, כדי שזה יעבוד גם בגרסת הניסיון.
6. ב־Vercel ← **Deployments** ← בפריסה האחרונה ⋯ ← **Redeploy**.

אחרי כמה דקות יופיע בכל שאלה הכפתור "יצירת הקראה אוטומטית".

אפשרות אחרת: Google Cloud Text-to-Speech, עם `GOOGLE_TTS_API_KEY`. גם לה יש מסלול חינמי חודשי.

## מבחן באנגלית או בערבית
שפת הקול נבחרת לבד לפי הטקסט: עברית, ערבית או אנגלית.

## בלי קובץ הקראה (לא מומלץ למבחן)
ב"הגדרות מתקדמות" של המבחן אפשר לסמן "מותר לפרסם שאלות בלי קובץ הקראה". אז שאלה בלי הקראה תוקרא בקול של המכשיר של כל תלמיד/ה. הקול הזה שונה ממכשיר למכשיר, ובחלק מהמחשבים אין בכלל קול בעברית. מבחנים שנוצרו לפני העדכון הזה מסומנים כך, כדי שימשיכו לעבוד כמו קודם.
